# 蒙特卡罗方法实验总结

## 一、实验目的

通过使用 Python 编写蒙特卡罗随机模拟程序，理解蒙特卡罗方法的基本思想，掌握利用随机点估算圆周率的方法，并学习使用 matplotlib 进行图形绘制。

## 二、实验过程

本次实验首先使用 Python 的 random 模块生成10000个随机点，根据点的坐标判断其是否位于四分之一圆内，再利用圆内点数与总点数的比例估算圆周率。

基础程序运行成功后，我进一步使用 matplotlib 绘制随机撒点图，用蓝色表示圆内点、红色表示圆外点，并用黑色曲线表示四分之一圆的边界。

为了研究随机点数量对估算结果的影响，我又编写了 compare.py，分别使用100、1000、10000、100000个随机点进行对比实验，并生成四组可视化图形。

## 三、实验结果

| 随机点数量 | 圆周率估算值 | 绝对误差 |
|---:|---:|---:|
| 100 | 2.840000 | 0.301593 |
| 1000 | 3.148000 | 0.006407 |
| 10000 | 3.114000 | 0.027593 |
| 100000 | 3.147000 | 0.005407 |

从实验结果可以看出，100个随机点时估算误差较大，而100000个随机点时误差相对较小。

但是，10000个随机点的误差反而大于1000个随机点的误差，说明蒙特卡罗方法具有随机性，不能保证每次增加随机点数量都会减小误差。

## 四、实验中遇到的问题

实验过程中主要遇到了 matplotlib 安装时网络连接失败的问题。后来通过更换 Python 软件包镜像源，成功安装绘图库。

在使用 GitHub 提交代码时，也遇到了 SSL/TLS 连接失败的情况。通过检查代理设置并临时使用 OpenSSL 后端，最终成功将代码和图片上传至 GitHub。

## 五、实验收获

通过这次实验，我进一步理解了蒙特卡罗方法的基本思想，发现除了利用数学公式直接计算圆周率，还可以通过随机模拟的方法进行近似估算。

在编写程序的过程中，我练习了 Python 的循环、条件判断、列表和随机数生成等基础知识，也学习了使用 matplotlib 绘制散点图和保存图形。

通过四组不同随机点数量的对比实验，我认识到随机点越多，估算结果通常越稳定，但单次运行并不能保证误差一定减小。

此外，我还进一步熟悉了 VS Code 和 GitHub 的使用，学会了通过 Git 保存不同阶段的代码，并解决了一些安装依赖和网络连接方面的问题。
